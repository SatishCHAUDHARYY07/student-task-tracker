# Student Task Tracker 🎯

A modern and user-friendly task management web application designed to help students organize their daily tasks, manage deadlines, and improve productivity.

## 📌 About the Project

Student Task Tracker helps students manage academic activities in one place. It provides multiple ways to view and organize tasks, making it easier to track progress and stay focused on goals.

## ✨ Features

- **Task Management:** Create and organize tasks.
- **Task List View:** View tasks in a structured list.
- **Kanban Board:** Organize tasks by their status.
- **Calendar View:** Manage tasks according to dates.
- **Pomodoro Timer:** Use focused work sessions to improve productivity.
- **Statistics Overview:** Review task progress and productivity.
- **View Controls:** Switch between different task views.
- **Responsive UI:** Designed for a convenient user experience.

## 🚀 Getting Started

### Prerequisites

Install the following on your computer:

- Node.js
- npm
- Git (optional, for cloning the repository)

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/SatishCHAUDHARY07/student-task-tracker.git
   ```

2. Open the project folder:

   ```bash
   cd student-task-tracker
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in the terminal, usually:

   `http://localhost:5173/`

## 🏗️ Build for Production

To create a production build, run:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```
